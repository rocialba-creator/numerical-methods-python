# Numerical Methods Library

This repository contains a collection of numerical methods implemented in Python for solving common mathematical problems.

The library is organized into five main modules:

---

## 📌 Modules description

### 1. Differentiation
Contains numerical methods for approximating derivatives.

Includes:
- Forward, backward and centered finite differences
- Higher-order finite difference schemes
- Derivative approximation from tabulated data

---

### 2. Integration
Implements numerical integration techniques for functions and discrete data.

Includes:
- Trapezoidal rule
- Simpson 1/3 rule
- Simpson 3/8 rule
- Composite integration methods
- Integration of tabulated data

---

### 3. Interpolation
Methods for constructing approximations of functions from discrete points.

Includes:
- Polynomial interpolation
- Linear interpolation
- Interpolation evaluation techniques

---

### 4. ODE (Ordinary Differential Equations)
Numerical methods for solving initial value problems.

Includes:
- Euler method
- Time evolution models (e.g., thermal systems)
- Basic differential equation solvers

---

### 5. Linear Systems of Equations
Iterative methods for solving systems of the form Ax = b.

Includes:
- Gauss-Seidel (simple and matrix form)
- Jacobi method (with relaxation)
- SOR method
- Convergence analysis using spectral radius

---

### 6. Root Finding Methods
Algorithms for solving nonlinear equations f(x)=0.

Includes:
- Bisection method
- Regula Falsi method
- Fixed point iteration
- Secant method
- Newton-Raphson method

---

## 🎯 Purpose

This library was developed as a practical implementation of numerical analysis methods, focusing on:

- Understanding numerical algorithms
- Comparing convergence behavior
- Applying methods to real mathematical problems
- Learning scientific programming in Python
