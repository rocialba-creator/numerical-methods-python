# numerical-methods-python
Numerical methods implemented in Python, developed and tested using PyCharm IDE. Includes root-finding, numerical integration, interpolation and differential equations.

## Contents

This project includes implementations and analysis of classical numerical methods used in scientific computing:

- Root-finding methods (Bisection, Newton-Raphson)
- Numerical integration techniques
- Interpolation methods
- Numerical solution of differential equations
- Error analysis and convergence study

## Purpose

The goal of this project is to apply numerical techniques to solve mathematical problems computationally and analyze the accuracy and stability of the methods.
