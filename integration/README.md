# Numerical Integration Methods

This module implements classical numerical integration techniques in Python, including the trapezoidal rule and Simpson’s rules (1/3 and 3/8).

The goal is to approximate definite integrals of real-valued functions and visualize the polynomial approximations used in each method.

## Methods implemented

- Trapezoidal rule
- Simpson’s 1/3 rule
- Simpson’s 3/8 rule
